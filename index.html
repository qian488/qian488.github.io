nums 的 三角和 是执行以下操作以后最后剩下元素的值：

  1. nums 初始包含 n 个元素。如果 n == 1 ，终止 操作。否则，创建 一个新的下标从 0 开始的长度为 n - 1 的整数数组 newNums 。

  3. 将 newNums 替换 数组 nums 。
  4. 从步骤 1 开始 重复 整个过程。
    请你返回 nums 的三角和。
